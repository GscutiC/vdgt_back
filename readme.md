# Proyecto Backend - DGT

Este proyecto es un backend desarrollado en Flask con una arquitectura hexagonal. Incluye soporte para CORS, middlewares y un modelo de usuario con soporte para identificadores faciales.

## Requisitos previos

Antes de comenzar, asegúrate de tener instalado lo siguiente:

- Python 3.8 o superior
- pip (el gestor de paquetes de Python)
- Virtualenv (opcional, pero recomendado)
